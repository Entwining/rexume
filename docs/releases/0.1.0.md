First public release.

rexume restores Rex sessions after the Rex server stops: layouts, each pane's working directory, and the Claude Code, Codex, or Pi conversation it ran, reopened with the model and effort it last used. A turn the server's end cut off continues once; panes you closed stay closed. `rexume task` lets an orchestrator agent register a worker pane, get one notice when the worker finishes, and have an unused disposable worker's pane closed after it acknowledges the result. `rexume status` lists restores that did not complete and notices not yet delivered.

Install on Apple Silicon macOS with `brew install entwining/tap/rexume`, then run `rexume install` to add the session hooks, the Pi extension, and the LaunchAgent that runs `rexume daemon`; `rexume uninstall` removes them. The README lists what Rex and the agents do not let rexume guarantee.
