Rexume now honors `CLAUDE_CONFIG_DIR`, `CODEX_HOME`, and `PI_CODING_AGENT_DIR` when installing, uninstalling, checking status, and refreshing integrations. The daemon's service keeps these values so upgrades refresh the same directories. Run `rexume install` again after upgrading to apply them to an existing installation.

Absolute paths are supported, along with `~` and `~/…` for Pi. Other nonempty values skip the affected runtime with a diagnostic. If omp is installed and `PI_CODING_AGENT_DIR` is set, Rexume skips the Pi extension to avoid loading it in omp.

Older installations may have entries in the default directories. To clean those up, run `rexume uninstall` with the directory variables unset, then install again with the configured values.
