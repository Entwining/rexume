rexume now runs on Linux, x86_64 and arm64, on the machine that runs the Rex server. Each release ships a static build for both architectures with a provenance attestation, and the README shows how to download and verify it. On Linux, `rexume install` writes and starts the systemd user service `rexume.service`, which logs to the journal, and the default server is `$XDG_RUNTIME_DIR/rex/server.sock`. If your Rex server keeps running after you log out, run `loginctl enable-linger` once so that the daemon does too. Linux 5.3 or later is required.

Three fixes apply on macOS as well:

- The daemon and `rexume task wait` could miss a change committed just as they woke, and wait for the next one.
- A pane whose first report reached the daemon before its session did could be saved without its directory, size, and program.
- A conversation record replaced while the daemon waited for the server was no longer followed, so turns written to the new file went unnoticed.
