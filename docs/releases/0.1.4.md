Upgrading rexume is enough again to update the Pi extension. When the daemon starts, as it does after every upgrade, it replaces `~/.pi/agent/extensions/rexume.ts` with the new version's extension if `rexume install` wrote the file and its content differs. It never creates the file, so an extension removed by `rexume uninstall` stays removed, and it leaves a file at that path that `install` did not write as it is. A failed refresh is logged in `~/Library/Logs/rexume.log` and does not stop the daemon.

`rexume uninstall` now stops the daemon before removing anything, so the daemon cannot write the extension back.

If you skipped the `rexume install` that 0.1.2's notes asked for, `brew upgrade rexume` now replaces that extension too.
