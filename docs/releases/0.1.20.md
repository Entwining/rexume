A Claude Code conversation that Rexume reopens now runs at the model and effort its last answer used. Before, it came back at the effort your settings or the model's default give, whatever it ran at with `--effort` or `/effort`, and with the model it started with, so a model chosen with `/model` was replaced. Rexume reads both from the conversation's transcript, keeping a context-window suffix such as `[1m]`. A turn that invoked a skill can run at the skill's own model and effort, so its answers are passed over; a model or effort changed after the last answer, or followed only by turns that invoked a skill, reopens at the one before. [The design's limits](https://github.com/Entwining/rexume/blob/v0.1.20/docs/design.md#limits) list these cases.
