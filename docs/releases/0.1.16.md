Rexume's notices and requests now reach Claude Code as your own prompts. Claude Code took them as messages from another session: the model read them with a note that you had not typed them, and a session that bypasses permission prompts held each one for your approval and dropped it when the approval went unanswered, which left a request's round open until its orchestrator abandoned it. A Claude Code plugin, `rexume`, now submits each message that starts with a Rexume token as your prompt. When Claude Code refuses a plugin's prompt, as it does after you stop a turn and until you type again, the message arrives as before. The plugin does not check that Rexume wrote the message, so another session's model can send one that starts with a token, as [the README's known limits](https://github.com/Entwining/rexume/blob/v0.1.16/README.md#known-limits) describe.

The daemon updates the plugin's files after an upgrade but never creates them, so run `rexume install` once after upgrading: it writes the plugin to `~/.local/share/rexume/claude-plugin` and registers it through the `claude` on your `PATH`. A Claude Code session started before that picks the plugin up when it starts again or on `/reload-plugins`. If a configuration manager owns `~/.claude/settings.json`, add [the marketplace and plugin entries `rexume install` registers](https://github.com/Entwining/rexume/blob/v0.1.16/docs/cli.md#how-install-recognizes-its-entries) to its source.

`task send` no longer fails while the task's round is running or blocked. The request waits in a new `queued` round and is sent once the rounds before it have finished and the worker is idle; it is never typed into the running turn. A queued round whose worker can take no further request, because its pane closed or its run ended, ends as `dropped` without its request being sent, and you get a notice for it. `task abandon --round N` drops a queued round before it starts.

`task add` now refuses a pane that another task not yet released has as its worker, and names that task. Two tasks on one worker each counted the other's turns as their own unread turns, so one task's `task next` took the other's result and its `task release` refused. Send further work for that worker to the task that holds it, or release that task first. Tasks already registered on one pane stay as they are.

A notice now names its task by title and keeps the task ID only in the commands it suggests.

The state database moves to schema version 9, which earlier versions of Rexume refuse to open.
