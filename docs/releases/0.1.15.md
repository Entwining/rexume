Rexume's state directory, `~/.local/state/rexume`, which holds task results and the final answer of each Claude Code turn, is now readable only by its user. Rexume used to create it with the default mode, so other accounts on the same machine could read what it saved. It now creates the directory and every directory in it with mode `0700`, whichever of the daemon, a hook, a task command, or the Pi extension needs one first, along with `~/.local` and `~/.local/state` when they do not exist yet.

The daemon restricts an existing state directory the same way when it starts, which it does after the upgrade, and logs `restricted` with the directory's path; nothing else is needed. The state database stays at schema version 8.
