A Claude Code worker's task result is now the turn Claude Code itself reports as finished. Rexume used to infer the end of a Claude Code turn from its transcript and the pane's status, which Claude Code does not mark: a turn could count as finished at a tool call or after a short idle, or wait for an answer the transcript did not hold yet. Claude Code's `UserPromptSubmit`, `Stop`, and `StopFailure` hooks now run `rexume report claude`, which keeps each turn's prompt ID, final answer or error, and a notice's or request's token, but no other prompt text, in a turn record in the state directory, and every task and restore reads Claude Code's turns from there.

A notice or request counts as received only once the Claude Code turn that took it in ends with an answer or an error, because Claude Code runs Rexume's hook for a prompt before another `UserPromptSubmit` hook of yours can reject it. A turn you interrupt, a prompt your hook rejects, or a turn the server's stop cut off that reopens without Rexume's continuation prompt ends as cancelled when the conversation takes its next input, and a request round whose request it carried ends `cancelled` without the request being sent again. A Claude Code `Stop` hook of yours that makes Claude Code go on after it finished responding now keeps the conversation going across a server stop: a restored pane continues it while its last status was still `working`. A released worker's pane is not closed while its status is `working` or `blocked`, and a `done` status that arrives after its result no longer keeps it open.

`rexume install` writes the three new hooks beside the `SessionStart` hook, and the daemon adds them on its first start after the upgrade to settings that already have Rexume's `SessionStart` hook, so upgrading needs no other step; a running Claude Code picks them up from its settings file. If a configuration manager owns `~/.claude/settings.json`, add [the entries `rexume install` recognizes](https://github.com/Entwining/rexume/blob/v0.1.14/docs/cli.md#how-install-recognizes-its-entries) to its source.

The state database moves to schema version 8, which earlier versions of Rexume refuse to open. The upgrade starts each Claude Code task's reading at the beginning of its new turn record, so a round still waiting when you upgrade takes the next turn its worker finishes; a request round whose request was sent but not yet seen received keeps waiting until you abandon it.
