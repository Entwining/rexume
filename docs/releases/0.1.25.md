A conversation that a signal ended now reopens at a restore. When macOS shuts down or the user logs out, the system ends the agents before the Rex server stops, so their panes looked as if the user had quit them, and a restore left the shell. Rexume now reopens such a conversation, without continuing a turn, when the runtime's own record shows that a signal ended it, Rex saw no other program in its pane since, and the conversation was not reported from another pane since. Pi and omp record how they ended; Claude Code and Codex record nothing that tells a signal from a quit, so their panes still keep the shell. After the upgrade, the daemon replaces the Pi extension, which a running Pi loads when it starts again.

The state database moves to schema version 11, which earlier versions of Rexume refuse to open.
