<!-- Written by `rexume install`, which keeps it current; `rexume uninstall` removes it. -->

Run `rexume skill show` and follow the guide it prints. The guide comes from the installed Rexume, so it describes the commands that version has, and it names the `rexume skill show TOPIC` to run before each action a topic covers.

If `rexume` is not found, Rexume is no longer installed: orchestrate with Rex's own guide alone.
